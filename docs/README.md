# WorldPass Documentation

Welcome to the WorldPass documentation pack. This project is an early-stage, MVP-first digital identity system built by a small team. Documentation is intentionally concise, realistic, and honest about current limitations.

Recommended reading order:
- New developers: start with `ARCHITECTURE_OVERVIEW.md`, then `FRONTEND_WEB_OVERVIEW.md`, and `CONTRIBUTING_GUIDE.md`.
- API consumers: go to `BACKEND_API_REFERENCE.md`.
- Security reviewers: start with `SECURITY_MODEL_AND_LIMITATIONS.md`.
- Stakeholders and planners: see `ROADMAP_MVP_vs_STAGE2_EAS.md`.

Index:
- `ARCHITECTURE_OVERVIEW.md` — High-level system design and data flows.
- `BACKEND_API_REFERENCE.md` — FastAPI endpoints and schemas.
- `FRONTEND_WEB_OVERVIEW.md` — Web app structure, routing, UX notes.
- `SECURITY_MODEL_AND_LIMITATIONS.md` — Auth, crypto, storage, and current risks.
- `ROADMAP_MVP_vs_STAGE2_EAS.md` — MVP scope and future EAS integration plan.
- `CONTRIBUTING_GUIDE.md` — Setup, tooling, and contribution checklist.
- `PRIVACY_POLICY.md` — Draft privacy policy for the MVP.
- `TERMS_OF_USE.md` — Draft terms of use for the MVP.

Landing page: The landing page links to Privacy and Terms and uses the `worldpass_logo.svg` branding.
