# Privacy Policy (MVP Draft)

This is a draft privacy policy for the MVP stage of WorldPass. It will evolve as the project matures.

## Scope
- Applies to the MVP version of WorldPass web/mobile and backend services.

## Data We Collect
- Account data: email and authentication-related information.
- Credential data: fields necessary to issue and display credentials.
- Usage events: optional analytics (disabled by default; see `evt.js`).

## Storage
- MVP aims to store sensitive credential data primarily on-device.
- Server-side storage is minimal (metadata/config), using SQLite or similar.

## Sharing
- We do not sell user data.
- Credentials are shared only when you actively present or QR-share them.

## Security
- The project is early-stage; no formal audit yet.
- Basic best practices are followed, but there may be risks and limitations.

## Your Choices
- You can request deletion of account data by contacting the maintainers.
- Optional analytics can be disabled; it is off by default in development.

## Changes
- This policy will change over time. Significant changes will be noted in release notes or the repository.

## Contact
- For privacy questions, open an issue or contact the maintainers listed in the repository.
